How it works

Generate content from a graph.

Connect nodes, adjust parameters and see the result update in your scene. Every graph is a regular asset in your project.

New to OctoShaper? The getting-started tutorial builds a reusable graph step by step, with a video companion.

Examples

What you will be able to build with Godot

Layouts, buildings, vegetation, splines and meshes, each generated by a graph.

Modular layouts

Walls, towers and houses placed by the graph, while you control the overall shape.

Buildings

Floors, windows and roofs from your own modular pieces, stacked by the graph.

Vegetation

Grass and small plants over large areas, drawn with GPU instancing.

Along splines

Bridges, walls and paths: your meshes placed and instanced along a curve.

Scattering

Points sampled on meshes and terrain, culled by slope, with props that sit on the ground.

Procedural meshes

Landmarks like this arena, generated from a few parameters instead of modelled.

Features

Build and tweak graphs inside Unity.

Visual graphs

Inspect every step.

  • Each node shows a thumbnail of its result
  • Change a value and the preview updates
  • The spreadsheet lists every element and attribute

Exposed parameters

Edit parameters in the Inspector.

  • Numbers, materials, textures and splines
  • The scene rebuilds while you tweak, in edit mode
  • Add one Procedural Graph Executor to any GameObject

Procedural meshes →

Agentoctoshaper skill

Use the OctoShaper skill to make a stylised rock graph. Expose the seed, point count and roughness.

I'll look up the nodes I need, then build and render the graph.

unity command octoshaper --operation catalog --request_json '{"query":"convex hull"}'→ Mesh.ConvexHull · Convex Hull Mesh
unity command octoshaper --operation iterate --request_file rock.iterate.json✓ saved Assets/Graphs/StylisedRock.asset✓ rendered perspective.png

Done. StylisedRock is saved, with Seed, Point Count and Roughness exposed.

AI integration

Let an agent build the graph.

  • Bundled agent skill, installed from Tools › OctoShaper › AI Integration
  • Agents search nodes, edit graphs and render previews through the Unity CLI (Unity 6)
  • The result opens in the graph editor like any other graph

In the editor

Tools for every step.

Scene view tools

Edit splines in the Scene view.

Bezier paths live in the graph settings. Drag their handles in the Scene view and the graph follows.

Scene view tools →

Preview Stage

Scene preview and gizmos.

Try ideas in an isolated stage without touching your open scene. Pin the preview to any node, and another node's points and edges as gizmos.

Preview Stage →

Reusable subgraphs

Graphs inside graphs.

Drop one graph into another like any node, preview included. Each copy gets its own parameter values.

Attributes and subgraphs →

For programmers

C# API.

  • Turn any static C# method into a node
  • Drive graphs from gameplay with parameter overrides
  • React to spawned prefabs with callbacks

Creating custom nodes →

Write your own nodes
[NodeDefinition(Id = "mygame.jitter", Name = "Jitter Positions")]
public static void JitterPositions(ElementSet elements, float magnitude = 0.5f)
{
    // Parameters show up as ports in the graph.
}
Drive graphs from gameplay
if (executor.TrySetParameterOverride("Seed", seed))
    executor.Evaluate();  // or await EvaluateAsync()
