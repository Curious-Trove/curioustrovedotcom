Samples

OctoShaper ships with a set of samples. Each one is a small, readable graph you can open, tweak and copy from.

Import a sample

  1. Open Tools > OctoShaper > Getting Started and pick a sample under Samples. UPM installs also list them in Package Manager.
  2. Open its scene, or add a Procedural Graph Executor to an empty GameObject and assign the sample graph.
  3. Tweak the parameters in the Inspector. Turn on Generate In Edit Mode to see changes live.

Each sample has a README describing its controls. The samples use URP materials. See Installation.

Frequently asked questions

How do I import the samples?
Open Tools > OctoShaper > Getting Started and choose a sample under Samples. UPM installations also list them in Package Manager.
Why are the sample materials pink?
The samples use URP materials. Switch the project to URP or replace the materials for your render pipeline.
